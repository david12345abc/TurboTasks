# TurboTasks Mobile

Android-приложение TurboTasks для авторизации, входа в проект и работы с проектной главной страницей.

## Запуск

Откройте папку `mobile` в Android Studio и дождитесь синхронизации Gradle.

Для локальной сборки нужен Android SDK, указанный в `local.properties`, например:

```properties
sdk.dir=C\:\\Users\\<user>\\AppData\\Local\\Android\\Sdk
```
